# Student Submission Rules

## Before starting
- Read the current GitHub Issue.
- Confirm the authorised assets, accounts, time window and tools.
- Ask a mentor when scope is unclear. Do not guess.

## Branch
Create one branch per assignment:

`week-XX/<track>/<github-username>-<task>`

## Commits
Use short meaningful commit messages, for example:
- `add authentication timeline`
- `document suspicious login evidence`
- `add fixed-version retest`

## Pull Request
Your PR must:
- link the assigned Issue;
- contain only your assignment work;
- include the required evidence;
- contain no secrets or private credentials;
- include a short summary of what you found;
- remain open for mentor review.

Students must not merge their own PR unless instructed.
