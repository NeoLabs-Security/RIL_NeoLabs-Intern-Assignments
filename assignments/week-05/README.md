# Week 05 — Operation Poisoned Upload

**Scenario:** `w05-poisoned-upload` · **Runtime:** HYBRID · **Status:** draft for mentor review; not a launch announcement.

## Business brief
The synthetic VCC learner application has a coursework-evidence upload feature. Some uploads appear to be accepted or rejected unexpectedly. Your organization must assess the behavior, investigate logs, contain approved suspicious content and confirm the corrected release works.

Week 05 is **cooperative, not a competition**. SOC, Grey-Box Pentest and IT Security Support each deliver their own evidence, findings and handoffs. Use the shared incident reference provided in your exercise materials.

## Safety and access
Only use the server-published target, scenario, account, track, pod and time window. No external domains, production content, other pods, live malware, executable payloads, remote code execution attempts, broad port scans, password guessing, denial of service, service restarts or direct host/database access.

Use only **mentor-supplied, harmless upload fixtures**. File content must be synthetic and non-executable. Stop after one bounded proof of the required behavior. If real user data, other-pod resources or unexpected infrastructure becomes visible, stop and report to a mentor.

Pentest and Support need the published W05 live window; SOC may use approved recorded/replayed telemetry when live access ends. Do not reuse a prior week's URL or credentials as authorization.
