# Module 3 — Burp Suite Community and Safe Proxy Workflow

This numbered module exists so the internship learning path has no missing document numbers.

## Primary material

Read the complete NeoLabs Burp Community setup guide at:

`docs/tool-setup/burp-community.md`

## What you should be able to do

1. Use Burp's dedicated browser or a dedicated training browser profile.
2. Proxy only the exact target authorised in your assignment.
3. Read HTTP history and identify methods, paths, parameters, headers and status codes.
4. Send one approved request to Repeater and change only one variable at a time.
5. Record redacted request/response evidence in your testing journal.
6. Stop when the assignment's proof threshold is reached.

## Before VCC testing
