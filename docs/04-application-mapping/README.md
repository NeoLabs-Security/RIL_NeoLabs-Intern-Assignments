# Module 4 — Application Mapping and Grey-Box Method

This numbered module exists so the internship learning path has no missing document numbers.

## Primary material

Use the NeoLabs Application Mapping Workbook at:

`worksheets/application-mapping-workbook.md`

## Workflow

1. Confirm your written target, testing window, accounts and Rules of Engagement.
2. Browse the normal application workflow before changing requests.
3. Build a role, route, endpoint, object and input inventory.
4. Record identifiers and expected ownership or permission rules.
5. Identify trust boundaries between browser, application, API and storage.
6. Write candidate hypotheses before performing a security test.
7. Validate only the minimum safe observation required by the assignment.

## Required practice

After completing the workbook, run `labs/local-access-control/` and use its interactive synthetic app to practise mapping and object-ownership reasoning.
